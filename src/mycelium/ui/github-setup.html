Connect GitHub to Mycelium

A server administrator registers a GitHub App once. Users can then connect repositories from Documentation → Models & GitHub without creating personal tokens.

Register the GitHub App

  1. Register an App with Contents and Pull requests permissions set to Read and write.
  2. Set the callback URL to https://YOUR_HOST/api/github/callback and setup URL to https://YOUR_HOST/api/github/setup. Enable Redirect on update. Leave Request user authorization during installation disabled.
  3. Disable webhooks. Allow installation on the intended GitHub accounts.
  4. Generate a private key and save the PEM file where only the Mycelium service account can read it.

Configure the server

Add the following to the server's environment. The systemd deployment uses /etc/mycelium.env. Restart the service after changing it.

MYCELIUM_GITHUB_APP_ID=123456
MYCELIUM_GITHUB_APP_CLIENT_ID=Iv1.example
MYCELIUM_GITHUB_APP_CLIENT_SECRET=<app-client-secret>
MYCELIUM_GITHUB_APP_SLUG=mycelium-docs
MYCELIUM_GITHUB_APP_PRIVATE_KEY_FILE=/etc/mycelium/github-app.pem
MYCELIUM_GITHUB_APP_CALLBACK_URL=https://YOUR_HOST/api/github/callback

The callback origin must match the address used to open Mycelium. HTTP is supported only on localhost or loopback. Setup uses a single server process and expires after ten minutes or a server restart.

Choose a repository

Return to Documentation → Models & GitHub → Documentation delivery. Choose Connect GitHub, select repositories in GitHub, and authorize access. Choose the repository and branch in Mycelium, then Use repository and Save documentation delivery.

If the App is already installed or an organization has now approved your request, choose Use existing GitHub installation. Your GitHub account must have write access to the repository.

Connections grant publishing access to this instance's writers. Publishing remains an explicit action. Disconnecting preserves documents and PRs; it does not uninstall the App. Restored backups require reconnection. Keep the App's private key and client secret separately from instance backups.
